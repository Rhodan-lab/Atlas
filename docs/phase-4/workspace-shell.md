## Purpose

Create the smallest replaceable static package that can expose the accepted read-only workspace export without modifying the accepted reference shell and without introducing browser-side workspace semantics.

The shell is a reader and navigator. Python rebuilds and validates the accepted export and manifest; the browser receives exact generated bytes and cannot change accepted order, decisions, candidate state, or cross-repository status.

## Deterministic routes

The shell data contains thirteen unique routes:

1. workspace overview;
2. five exact ordered entry routes;
3. advisory candidates;
4. separate Principia status;
5. warnings;
6. open questions;
7. limitations;
8. export evidence;
9. a complete text-only summary.

Every entry route exposes the exact accepted reference, decision, position, rationale, visible lifecycle, review, staleness, and provenance metadata. Unknown routes fail explicitly and refuse silent fallback.

## Browser-state boundary

The application uses only:

- a deterministic URL hash;
- the current in-memory route;
- the previous valid route for explicit recovery;
- verified local export bytes for download.

It does not use `localStorage`, `sessionStorage`, accounts, cloud persistence, analytics, plugins, repository credentials, WebSockets, or event streams.

## Local download

The application verifies the accepted export SHA-256 before enabling download. The download uses the already loaded exact bytes and creates no network request, canonical write, lifecycle event, review record, merge instruction, release action, or repository mutation.

Browser automation must later prove the downloaded file is byte-identical to the accepted export.

## Static evidence requirements

The pinned candidate workflow proves on Python 3.11 and 3.13:

- deterministic shell data and build report;
- deterministic package bytes across two builds;
- exact accepted export and manifest bytes;
- thirteen unique routes and five preserved entry positions;
- no implicit `latest` route;
- local-only semantic HTML, CSS, and JavaScript;
- no canonical or repository authority;
- no account, API, cloud, external network, live Principia dependency, or production architecture;
- local HTTP serving of all required package files.

## Browser evidence deferred

This PR does not claim keyboard, focus, route-history, responsive, reduced-motion, zero-external-request, or download evidence in a real browser. Those claims require a separate pinned Chromium evidence candidate after the static package is accepted.
