# Atlas Roadmap

## Phase 1 — Native graph foundation ✅

- C++ concept and relation model
- portable `.atlas` persistence
- weighted text queries
- graph traversal
- CLI and unit tests

## Phase 2 — Polyglot foundation ✅

- Python source-note compiler
- Rust retrieval process
- C++ JSON command contract
- TypeScript API and local web explorer
- SQL persistence design
- independent and integration CI

## Phase 3 — Durable knowledge workspace

- SQLite repository implementation
- migration runner and schema versioning
- transactional graph edits
- claim-level evidence and confidence
- import/export compatibility tests
- incremental search index

## Phase 4 — Research and synthesis

- document chunk ingestion
- citation-aware claims
- contradiction and duplicate detection
- graph-assisted research trails
- saved queries and derived views
- provenance ledger

## Phase 5 — Interactive atlas

- spatial graph explorer
- timelines, prerequisite paths, and scale views
- offline desktop packaging
- plugin boundary for domain-specific analyzers
- synchronization without surrendering local ownership

## Non-goals until the foundation is stable

- autonomous rewriting of user knowledge;
- opaque vector-only retrieval;
- cloud account requirements;
- a plugin marketplace before contracts are versioned;
- adding languages without an independently useful boundary.
