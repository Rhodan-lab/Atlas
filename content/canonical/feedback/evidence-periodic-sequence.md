Apply `x[t+1] = x[t] - x[t-1]` from `x0 = 1` and `x1 = 0`:

```text
x0..x7 = 1, 0, -1, -1, 0, 1, 1, 0
```

The recurrence is deterministic in the ordered pair `(x[t], x[t-1])`. At `t = 1`, the pair is `(x1, x0) = (0, 1)`. At `t = 7`, it is `(x7, x6) = (0, 1)` again. Therefore every later state repeats with period dividing 6. Periods 1, 2, and 3 are excluded by the first six states, so the orbit has exact period 6. This remains model-derived evidence, not empirical evidence about a real system.
